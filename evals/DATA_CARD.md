# Smoke dataset

The 20 synthetic Python diffs are original MIT-licensed fixtures. Ten include a conspicuously named credential-like constant and ten change a retry count. They are deliberately repetitive and pin the orchestration contract. The fixture provider looks for the planted marker, so its score measures deterministic plumbing.

The real-model runner accepts frozen JSONL with unique `id`, unified `diff`, boolean `vulnerable`, `category`, and optional `scanner_summary`. Use source and repository metadata to prevent related changes from crossing tuning and evaluation splits. Keep raw diffs out of saved dashboard reports. A public security benchmark needs a separate provenance and licensing review before adoption.
